■ フォルダ構成
─────────────────────────────────────────
japanese_ocr_app/
├── app.py            ← アプリ本体
├── database.py       ← SQLite データベース操作
├── version.py        ← バージョン情報
├── japanize.py       ← 中国簡体字→日本漢字 変換モジュール
├── custom_dict.txt   ← ユーザー追加 文字変換テーブル
├── config.json       ← エンジン選択の設定（自動生成）
├── ocr_history.db    ← OCR 履歴データベース（自動生成）
├── requirements.txt  ← 必要パッケージ一覧
├── setup.bat         ← 初回セットアップ用
├── run.bat           ← アプリ起動用
└── README.txt        ← この説明書
─────────────────────────────────────────

■ 動作環境
  - Windows 10 / 11
  - Python 3.9 以上（https://www.python.org/）
  ※ Python インストール時に「Add Python to PATH」にチェックを入れてください

────────────────────────────────────────────────────────────
  【はじめてのセットアップ手順】
────────────────────────────────────────────────────────────

1. Python をインストールする（まだの場合）
   → https://www.python.org/downloads/

2. setup.bat をダブルクリックする
   → 仮想環境の作成 & パッケージの自動インストールが行われます
   → 初回は RapidOCR のモデルダウンロードのため数分かかります

3. 完了メッセージが表示されたら準備完了！

────────────────────────────────────────────────────────────
  【毎回の使い方】
────────────────────────────────────────────────────────────

1. run.bat をダブルクリックしてアプリを起動
2. 「参照…」ボタンで PDF ファイルを選択
3. 「OCR エンジン」で RapidOCR / Mistral OCR / Surya OCR を選択
   → 選択したエンジンは次回起動時も自動的に記憶されます
4. Mistral OCR を使う場合は「Mistral API キー」欄に API キーを入力
   → 環境変数 MISTRAL_API_KEY が設定されていれば自動で読み込まれます
5. 「OCR 開始」ボタンをクリック
   → 初回は言語モデルのダウンロードが行われるため少し時間がかかります
   → 2回目以降はすぐに処理が始まります
6. 処理中は「キャンセル」ボタンでいつでも中断できます
   → 中断時はそれまでに取得できた結果が表示されます
   → 処理状況は経過時間とともにリアルタイム表示されます
7. 画面下部に OCR 結果が表示されます
   → Surya OCR では、表（テーブル）が検出された場合に
     Markdown 表形式で出力されます
8. 「テキスト保存」ボタンで .txt ファイルとして保存できます
9. OCR 結果は自動的に SQLite データベースにも保存されます
   → 「DB 閲覧」ボタンで過去の OCR 履歴を検索・閲覧できます

────────────────────────────────────────────────────────────
  【OCR エンジン】
────────────────────────────────────────────────────────────

▼ RapidOCR（ローカル・無料）
  - PC 上で処理します
  - PDF の内容は外部サーバーに送信されません
  - 初回のみモデルダウンロードにインターネット接続が必要です
  - PDF 内にテキスト層がある場合は、画像OCRより先にテキスト層を抽出します

▼ Mistral OCR（API・高精度）
  - Mistral API に PDF を送信して処理します
  - 利用には Mistral API キーが必要です
  - アプリの「Mistral API キー」欄に直接入力するか、
    環境変数 MISTRAL_API_KEY にあらかじめ設定してください
    例: setx MISTRAL_API_KEY "あなたのAPIキー"

▼ Surya OCR（無料・高品質）
  - PC 上で処理する無料の高品質 OCR エンジンです
  - PDF の内容は外部サーバーに送信されません
  - 90以上の言語に対応、日本語の認識精度も高い
  - Transformer ベースの検出＋認識モデルを使用
  - レイアウト検出により、表（テーブル）を自動認識して Markdown 形式で出力します
  - CPU でも動作します（1ページあたり数秒～十数秒）
  - 初回起動時にモデルを自動ダウンロードします
  - インストール: pip install surya-ocr
  - 詳細は Surya 公式ドキュメントを確認してください
    https://github.com/VikParuchuri/surya

────────────────────────────────────────────────────────────
  【日本語テキスト正規化】
────────────────────────────────────────────────────────────

OCR 結果に中国簡体字が混入することを防ぐため、japanize.py が
約 280 文字の中国漢字を自動で日本漢字に置換します。
（日本語として正しい漢字には一切手を加えません）

追加の変換が必要な場合は custom_dict.txt に以下の形式で追記してください:
  例:  实施 = 実施
  例:  图书馆 = 図書館
編集後は OCR 実行時に自動で再読み込みされます（アプリ再起動不要）。

────────────────────────────────────────────────────────────
  【バージョン情報と設定保存】
────────────────────────────────────────────────────────────

▼ バージョン表示
  アプリのタイトルバーと画面上部に、現在のバージョン番号と
  リリース日が表示されます（version.py で管理）。

▼ エンジン選択の保存
  選択した OCR エンジンは自動的に config.json に保存され、
  次回起動時に前回と同じエンジンが選択されます。
  ※ config.json は .gitignore に含まれているため、
    動作環境ごとに個別に管理されます。

▼ 経過時間表示
   OCR 処理中は、ステータスバーに経過時間と処理済みページ数が
   リアルタイムで表示されます。

────────────────────────────────────────────────────────────
  【SQLite データベース（OCR 履歴管理）】
────────────────────────────────────────────────────────────

OCR 結果は自動的に ocr_history.db（SQLite）に保存されます。
保存される情報は以下のとおりです:

  - 登録日（YYYY-MM-DD）
  - 登録時間（HH:MM:SS）
  - タイトル（読み込んだ PDF ファイル名）
  - OCR 種別（使用したエンジン名）
  - ページ数
  - SOURCE（元 PDF のファイルパス）
  - OCR 結果テキスト

▼ 重複時の動作
  同じファイル名＋同じ OCR 種別で OCR を再実行すると、
  既存のレコードが上書きされ、登録日・登録時間が最新に更新されます。

▼ DB 閲覧画面
  「DB 閲覧」ボタンを押すと OCR 履歴管理画面が開きます:
  - 過去の OCR 結果を一覧表示
  - タイトルまたは OCR テキスト内容でキーワード検索
  - 選択したレコードの OCR テキストを詳細表示
  - 「この結果を表示」でメイン画面の結果欄に読み込み
  - 不要なレコードの削除

────────────────────────────────────────────────────────────
  【よくあるトラブル】
────────────────────────────────────────────────────────────

▼ setup.bat で「Python が見つかりません」と表示される
  → Python を再インストールし、「Add Python to PATH」にチェックを入れてください

▼ OCR 結果が文字化けする
  → テキストファイルを開く際に「UTF-8」エンコーディングを選択してください
  → メモ帳の場合：ファイルを開く → エンコード: UTF-8 を選択

▼ OCR の精度が低い
  → PDF の解像度が低い場合は精度が下がります
  → 元の画像が鮮明であるほど認識率が向上します

▼ 特定のページだけ結果が出ない
  → ページ単位でエラーが発生しても、他のページの結果は保持されます
  → 該当ページに「エラー」と表示される場合は、そのページの画像が破損している可能性があります

────────────────────────────────────────────────────────────
  【注意事項】
────────────────────────────────────────────────────────────

・RapidOCR を選んだ場合、処理はローカルで行われます
・Mistral OCR を選んだ場合、PDF の内容は Mistral API に送信されます
・Surya OCR を選んだ場合、処理はローカルで行われます
・Surya OCR の初回起動時のみ、言語モデルのダウンロードにインターネット接続が必要です
・RapidOCR の初回起動時のみ、言語モデルのダウンロードにインターネット接続が必要です
